# ADR-175 — AI Source Traceability

## Status

Approved (Phase 3Q)

## Context

When an AI assistant explains a financial insight or makes a factual claim to an investor, the system must be able to audit and verify where that fact originated. LLM systems often invent source citations, URLs, or external documents when provenance is opaque.

## Decision

1. **Contract-Internal Traceability**: Every fact in `PortfolioAiGroundingContextV1` carries a `source` block:
   ```typescript
   source: {
     contract: 'PORTFOLIO_INTELLIGENCE_SUMMARY_V1',
     path: string // e.g. "currencies.BRL.performance.twr"
   }
   ```
2. **Deterministic Path Resolution**: Every `source.path` corresponds directly to an existing property on the input `PortfolioIntelligenceSummary`. Synthetic or invented paths are forbidden and verified by automated architecture tests.
3. **No Fabricated External Citations**: Grounding does not produce fake URLs, internet links, or external bibliographic references for internally derived portfolio metrics.

## Consequences

- Full audibility: every statement generated by future AI components can be mapped back to the exact summary field that provided the number.
- High trust and auditability for compliance and user transparency.
